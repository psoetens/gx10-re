## Knob-address structure

Every effect uses the same 4-byte slot pattern at offset stride 0x04:
- offset +0x00..+0x02 = FX TYPE / ON-OFF / DupNum (header)
- offset +0x03 = FX Param 1 (often a sub-type or mode)
- offset +0x07 = FX Param 2 (first knob, knob_idx 0)
- offset +0x0B = FX Param 3 (knob_idx 1)
- offset +0x0F = FX Param 4 (knob_idx 2)
- ... offset +0x03 + (N-1)*4 = FX Param N

Each FX Param is 4 bytes, 4-nibble offset binary (`display = (raw - 0x8000)`).

Address byte 4 must be ≤ 0x7F (Roland 7-bit-per-byte rule), so FX Param 1..32 are reachable in segment 0 (offsets 0x03..0x7F). Effects in this catalog use ≤21 params (max observed offset = 0x53), so the segment-2 region (offsets 0x80..0xFF, addressed via 0x10001200..0x1000127F) appears unused.
